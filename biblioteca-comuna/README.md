50 de originale, câte 10 pentru **interior, exterior, panouri 3D, riflaje și produse/detalii**, la 1122 × 1402 px. Concepte AI fără texte sau prețuri; asocierea cu un SKU se verifică înainte de folosire într-o postare de produs.

`decoflair-inspiratie-50` este o legătură către colecția originală `../decoflair-inspiratie-50/`. Imaginile sunt accesibile direct din biblioteca comună, fără copii suplimentare și fără schimbarea căilor deja folosite de proiecte. Colecția și legătura sunt versionate în Git și disponibile ambilor agenți după `git pull`.

`colectii.json` este registrul colecțiilor; căile din el sunt relative la acest folder. Catalogul fiecărei colecții păstrează metadatele și proveniența imaginilor.

Salvează decupajele și creativele noi în folderul proiectului, păstrând originalele. Pentru producția de materiale creative se aplică [fluxul creativ comun](../FLUX-CREATIV.md).
