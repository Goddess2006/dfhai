# workspace

Un singur codebase: `/home/dfh/workspace`.

Codex și Claude Code lucrează aici, pe branch-ul `main`. Remote-ul este `git@github.com:Goddess2006/dfhai.git`.

## Regula

- Branch-ul de lucru este `main`.
- Commit și push se fac pe `main`.
- Înainte de modificări: `git checkout main` și `git pull --rebase origin main`.
- După modificări: actualizează `HANDOFF.md`, commit, `git push origin main`.
- Dacă push-ul este respins: `git pull --rebase origin main`, apoi push din nou.
